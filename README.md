# Bang! 온라인 (개인용 · 모바일 우선)

Bang! 기본판을 스마트폰 세로 화면에서 4~7명이 실시간으로 즐기는 웹 게임입니다. 인물은 직접 그린 오리지널 일러스트, 카드/아이콘은 오픈 라이선스 아이콘(game-icons.net)을 씁니다. 홈 화면에 설치하는 PWA로도 쓸 수 있습니다.

## 실행

```bash
npm install
npm start          # http://localhost:3000  (포트 변경: PORT=4000 npm start)
```

폰에서 접속하려면 HTTPS 주소가 필요합니다 → **[DEPLOY.md](DEPLOY.md)** (임시 터널 / Render 무료 / Fly.io)

## 첫 화면

**혼자 연습**(봇과 대결, 인원 선택) / **멀티플레이** → **방 만들기**(비공개 체크 가능) 또는 **참가하기**(열려 있는 방 목록에서 선택, 비공개 방은 코드로 입장). 초대 링크(`?room=코드`)로 열면 바로 참가 화면입니다.

## 한 판 모드 (기본)

기록·순위 없이 모여서 한 판 하는 용도가 기본입니다. 게임이 끝나면 **승리 팀**과 **POM(이번 판 MVP)** + 활약 순위가 나옵니다.
POM 점수: 적 처치(+3) · 가한 피해(+1) · 방어(+0.7) · 맥주(+1) · 끝까지 생존(+2) · 승리 팀(+4) · 배신자 승리(+2) · 아군 처치(−3)/아군 피해(−1).
기록/ELO 를 쓰고 싶으면 `RECORDS=on` (DEPLOY.md 참고).

봇과 할 때 ☰ 메뉴 → 봇 진행 속도 → **직접**을 고르면 봇 차례마다 "다음 ▶"을 눌러야 진행됩니다.

## 모바일 UX

- 상대는 **타일**로 표시 (체력 점, 손패 수, **거리**, 장착 카드). 사거리 안의 상대는 거리 숫자가 초록색
- 손패는 하단 트레이. **카드를 탭 → 설명 확인 → [사용]** 의 2단계라 오터치가 없습니다. 대상이 필요하면 타일을 탭
- 응답(빗나감!/맥주 등)도 같은 방식. 필요한 카드만 파란 테두리로 강조
- 상대 타일/내 패널을 탭하면 캐릭터 능력·장착 카드 설명, ☰ 메뉴에 도움말(규칙·카드·캐릭터)
- 내 차례/응답 차례에 진동, 게임 중 화면 꺼짐 방지, 앱 전환 후 돌아오면 즉시 재접속
- 접속이 45초 이상 끊기면 봇이 대신 플레이, 돌아오면 다시 직접 조작
- **혼자 연습하기**: 서버 없이 브라우저 안에서 봇과 대결 (4~7인)
- **행동 읽기**: 상대 타일에 그 사람의 마지막 행동이 표시되고, 타일을 누르면 그 사람의 최근 행동·관련 기록이 시간순으로 나옵니다. 상단 안내판에는 최근 4줄이 보이고, ☰ 메뉴에서 봇 진행 속도(느리게/보통/빠르게)를 조절할 수 있어요.
- **디자인**: 서부 술집 테마(나무·황동·트럼프 카드). 아이콘은 모두 game-icons.net(CC BY 3.0) 한 세트로 통일했고 이모지는 쓰지 않습니다. 글꼴 Rye / Special Elite / Black Han Sans(OFL)은 `public/fonts/`에 포함. 소재는 `tools/build-assets.js`로 다시 만들 수 있어요.
- **기록 · 순위**: 사람 2명 이상이 끝까지 한 판만 서버의 `data/stats.json`에 저장 (기기 코드로 식별, 로그인 없음). 역할 난이도를 반영한 ELO, 역할별/캐릭터별 전적, 순위표. 자세한 내용과 주의점은 DEPLOY.md

## 구현 범위

- 기본판 80장 덱, 캐릭터 16종, 역할 4종(4~7인 구성), 서버 권위형(타인의 손패/역할은 전송되지 않음)
- 테스트: `npm test` (규칙 23개 + 레이팅/저장/기록 9개 + 서버 통합 6개 + 봇 500판 시뮬레이션: 카드 80장 보존, 체력/상태 불변식 검사)

## 알려진 차이점

- 카드 무늬/숫자는 실제 카드와 정확히 같지 않고 52장 + 28장 무작위 배치로 근사 (다이너마이트 ♠2~9, 감옥/술통 ♥ 판정 확률은 거의 동일)
- 술통 판정은 뱅!을 맞는 즉시 자동 진행
- 확장팩(Dodge City 등)과 3인 플레이는 미구현
- 아이콘 저작자 표기: game-icons.net (Lorc, Delapouite, Skoll 외, CC BY 3.0) — 앱 도움말 하단과 `public/fonts/LICENSE.txt`에 표기
- 방/게임 상태는 서버 메모리에만 있어 서버가 재시작되면 사라집니다 (기록만 파일에 남음)
- 역할 난이도의 초기값은 봇 시뮬레이션 기반이라 실제 사람 승률과 다를 수 있어요 (특히 배신자). 판이 쌓이면 자동 보정됩니다

## 구조

```
game.js             규칙 엔진 (순수 로직, 상태 머신)
bot.js              봇 AI (빈 자리 / 끊긴 플레이어 / 연습 모드)
server.js           HTTP + WebSocket, 방/재접속/하트비트, 기록 연동
lib/ratings.js      역할 난이도 반영 ELO     lib/store.js  JSON 파일 저장소     lib/recorder.js  종료된 판 기록
tools/calc-priors.js  역할별 기본 승률 시뮬레이션
lib/engine-bundle.js  game.js + bot.js 를 브라우저용으로 묶음 (/engine.js 로 제공)
public/             index.html, style.css, app.js, icons.js(서부풍 아이콘), portraits.js(인물 일러스트), fonts/, sw.js, manifest, 앱 아이콘
test/               rules.js, ratings.js, server-stats.js, sim.js
Dockerfile, render.yaml, fly.toml   배포 설정
```
